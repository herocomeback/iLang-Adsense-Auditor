# iLang AdSense Auditor — MCP 专属黄金提示词模版集

本文档专门提供在使用 **iLang AdSense Auditor (MCP + Skill)** 时【开箱即用】的黄金提示词模版。

基于我们内置的 **29 项完整性硬闸门 (`audit_validator.py`)**、**五维判断向量 (`AUDIT_JUDGE_v1`)** 和 **本地代码原址代修能力**，你不再需要像旧版提示词那样繁琐地要求 AI“不准漏项”，只需选择对应场景直接复制使用即可。

---

## 一、 提示词使用 4 大黄金法则

1. **最好同时提供【本地工程路径】与【线上 URL】**：
   - 只给 URL 只能看渲染页面；同时给出本地绝对路径（如 `/Users/xxx/Projects/my-app`），MCP 会自动触发本地代码扫描（扫描 `robots.txt`、`ads.txt`、假按钮、PII、法务页面、路由结构），精度最高！
2. **显式要求“按性价比排期”**：
   - 系统独有 `imp`（致命度）与 `fix`（易修度）计算，要求“性价比排期”会让 AI 把“既卡审核、又极其容易修”的问题排在最前面。
3. **触发“主动代修闭环”（最强功能）**：
   - 在提示词末尾加入：**“诊断完成后，请直接在本地工程中帮我修改代码”**。AI 会自动在本地工程中补全 Privacy Policy、创建 `robots.txt` 或优化富文本结构。
4. **拒审诊断时，粘贴【AdSense 拒信原文】**：
   - 收到“低价值内容”、“网站尚未准备好”等拒信时，直接把官方界面/邮件文本贴给 AI，系统会自动将拒信映射到具体规则。

## 二、 5 大场景 Ready-to-Copy 提示词模版

### 模版 1：一键全能诊断 + 本地代码直接代修（🌟 最常用 / 推荐）

```text
请用 adsense-auditor 结合本地代码和线上站点帮我做全量合规诊断：

- 本地路径：/Users/wanghuan/Projects/你的项目
- 线上 URL：https://你的域名.com
- 阶段：申请前预查

要求：
1. 跑一遍 29 项完整性校验与静态证据预查（含 PII、假按钮、COPPA、WAF 等）。
2. 先给一段不懂技术也能看懂的人话结论（能不能申请、卡在哪、先修哪个）。
3. 按照“既卡审核、又容易修”的性价比顺序给出修复排期表。
4. 诊断完成后，请直接在本地工程里帮我改好排在前面的问题代码！
```

---

### 模版 2：被拒后的精准诊断与内容深度扩充（针对低价值内容 / 网站尚未准备好）

```text
我的网站 AdSense 申请被拒了，请用 adsense-auditor 帮我诊断原因并给出内容扩充方案：

- 本地路径：/Users/wanghuan/Projects/你的项目
- 线上 URL：https://你的域名.com
- AdSense 拒信原文：
  【在此粘贴后台拒信，例如：低价值内容 / 网站尚未准备好 / 请确保您的网站符合 AdSense 计划政策】

要求：
1. 将拒信映射到具体规则（如 CNT-01 / DIS-01），分析是结构异常、爬虫抓不到文本，还是缺乏信息增量。
2. 给出具体要增加哪些长文/指南/知识表格，以及代码层面的修改方案。
3. 直接帮我在本地工程中创建/优化缺失的富文本与合规代码。
```

---

### 模版 3：修复后的复审验证（重新提交审核前）

```text
我已按上次的建议修好了网站代码，请用 adsense-auditor 帮我复审是否可以重新提交申请：

- 本地路径：/Users/wanghuan/Projects/你的项目
- 线上 URL：https://你的域名.com
- 已修复项：
  - 增加了 Privacy 页面和 Cookie 声明
  - 在游戏页/主页底部增加了富文本科普指南和 Lookup 表格

要求：
1. 重新跑一遍 29 项硬闸门校验，确认是否还存在 Blocking 阻断项。
2. 给出重新提交的最佳时间点提示（如提示上线部署与 GSC Sitemap 重新抓取间隔）。
```

---

### 模版 4：跨项目 / 跨目录诊断（无需切换当前窗口）

```text
请用 adsense-auditor 帮我诊断本地另一个项目路径：

- 目标工程绝对路径：/Users/wanghuan/Projects/另一个项目名称
- 线上 URL：https://another-site.com (可选)

请抓取该路径下的静态证据（robots.txt、ads.txt、路由与法务页面），给出 29 项矢量诊断与性价比修复建议。
```

### 模版 5：极简一句话 Prompt（快捷触发）

```text
用 adsense-auditor 诊断当前工程，按性价比给出修复排期，并直接帮我改好本地代码。
```
