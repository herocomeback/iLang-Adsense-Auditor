# 在腾讯 WorkBuddy 里用

WorkBuddy 是腾讯出的桌面 AI 助手,能读写你电脑上的文件、连微信。如果你想让 AI **直接帮你改网站**,这是门槛最低的一条路。

## 你需要先准备

- 装好 WorkBuddy(去腾讯云官网下载,支持 Windows 和 macOS,装完扫码授权即可)
- 你要审核的网站地址

## 最简单的装法:一句话

WorkBuddy 支持直接从 GitHub 装技能。在 WorkBuddy 的对话框里说:

```
搜索安装 GitHub 上的 iLang AdSense 审核器
```

或者把仓库地址给它:

```
帮我安装这个技能:https://github.com/adsorgcn/iLang-Adsense-Auditor
```

它会自动把技能装好。装完之后,在对话框里点【技能】能看到它,确认是开启状态。

## 开始审核

装好后,直接说:

```
帮我审核 https://我的网站.com 能不能申请 Google AdSense
```

WorkBuddy 会抓取你的网站、逐条检查、跑一遍完整性自检,然后给你报告。

## 让它直接帮你改(WorkBuddy 的强项)

WorkBuddy 能读写你电脑上的文件。如果你的网站源码就在这台电脑上,审完之后它会主动问你「**需要我直接帮你改好吗**」。你说「改」,它就按「先改最划算的」顺序动手,每改一处告诉你改了什么、为什么这样改能过审。

如果改动涉及删内容、改主题、动 robots.txt 这类有风险的操作,它会先讲清后果、征得你同意再动手。

## 一个安全提醒

WorkBuddy 装第三方技能时,建议先让它跑一次技能审查(WorkBuddy 自带 Skill 安全审查功能)。这个技能是纯审核 + 修复工具,不碰你的密码、不上传你的数据,可以放心用。

## 关于装的位置

WorkBuddy 的技能装在 `~/.workbuddy/skills/` 目录下,你不用管这个——一句话安装它会自己处理好。想手动管理已装技能,在对话框点【技能】就能看到列表、随时开关。
