# 在 Claude 网页版 / 手机 App 里用

这是最简单的一条路。适合大多数人。

## 你需要先准备

- 一个 Claude 账号(网页版 claude.ai 或手机 App 都行)
- 你要审核的网站地址(比如 `https://我的网站.com`)

就这两样。不需要装任何东西,不需要懂代码。

## 三步开始

**第一步:打开 Claude**
网页版访问 claude.ai,或打开手机上的 Claude App,登录。

**第二步:直接说出你的需求**
在对话框里输入(把网址换成你自己的):

```
帮我审核 https://我的网站.com 能不能申请 Google AdSense
```

**第三步:等它给你报告**
Claude 会抓取你的网站、对照 Google 的 29 条要求逐条检查,然后给你一份报告:能不能现在申请、卡在哪几个地方、按什么顺序修。

## 让它顺手帮你改

网页版 Claude 看不到你服务器上的文件,所以它没法直接替你改网站。但它会把每个问题**怎么改**写成你能照做的具体步骤——改哪个文件、加哪几行、放在什么位置。你照着改就行。

如果你希望 AI 能**直接动手改**你的网站文件,那要用 Claude Code 或 WorkBuddy 这类能读写文件的工具,看对应的教程。

## 想让报告更准?

如果你手头有网站的源代码,可以在对话里把关键文件贴给 Claude,或者描述你的网站是用什么搭的(WordPress、自己写的、某个建站工具)。信息越全,报告里「暂时无法判断」的项就越少。

## 关于这个技能怎么在网页版生效

Claude 网页版会根据你的问题自动匹配合适的技能。你只要把需求说清楚(「审核我的网站能不能申请 AdSense」),它就会用上这套审核逻辑。你不需要手动「安装」什么。

如果你是团队/企业版用户,管理员可能需要在设置里启用相关技能——具体看你们的 Claude 版本设置。个人版直接问就行。
