# 在飞书智能伙伴里用

如果你的团队在用飞书,可以把这个审核器装进飞书的智能伙伴(aily),让它常驻在你的飞书里随时审。

## 你需要先准备

- 一个飞书账号,且你的企业开通了飞书智能伙伴 / aily
- 你要审核的网站地址

## 装法

飞书 aily 的技能通过 SkillHub 管理。最省事的方式是用自然语言让智能伙伴帮你找和装:

```
帮我找一个审核网站能不能申请 Google AdSense 的技能并装到我的助手里
```

如果你是开发者、想直接上传,飞书 aily 支持通过上传或编辑 SKILL.md 创建技能并发布到技能商店。你可以把本仓库 `skill/` 目录下的内容按飞书的技能格式上传。发布后会经过飞书的质量评估和安全扫描。

## 开始审核

装好后,直接对智能伙伴说:

```
帮我审核 https://我的网站.com 能不能申请 Google AdSense
```

## 重要:飞书环境下的「降级模式」

这个审核器有一个用 Python 写的完整性自检程序,它的作用是**从代码层面确保 29 条要求一条都没漏查**。

但飞书 aily 的部分技能形态**不能执行 Python 代码**。在这种情况下,审核器会自动**降级为模型自查**——它仍然会对照 29 条要求逐条核对,但确认「没有遗漏」这件事由 AI 自己完成,而不是由程序强制。

**这不影响审核质量,但你会在报告里看到一句诚实标注:** 「本次审核未经过代码级完整性校验,29 条要求由模型逐条自查覆盖。」看到这句话是正常的,说明审核器在如实告诉你它的工作方式。

如果你希望享受**代码级**的完整性保证(程序强制、一条都漏不掉),可以改用能执行代码的环境——比如 Claude Code、Codex、OpenClaw、WorkBuddy。审核逻辑完全一样,只是多了一道程序把关。

## 让它帮你改

飞书智能伙伴的权限跟你本人一致。如果它有权访问你的相关文件,可以协助修改;如果没有,它会把每处怎么改写成具体步骤给你。
